# lazeeza.nauflow.com

The short link to the Lazeeza app. `https://lazeeza.nauflow.com/#<code>` forwards to the launcher
(https://n4ufan.github.io/lazeeza-app/, repo n4ufan/lazeeza-app), which opens the app with that code.
The code is after `#`, so browsers never send it to a server. Nothing secret is in this repo.

DNS (Hostinger, nauflow.com): CNAME `lazeeza` → `n4ufan.github.io`.
